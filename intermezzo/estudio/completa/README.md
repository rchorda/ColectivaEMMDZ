# Intermezzo · Vídeos de estudio

Parte de Violín I con cuatro compases de introducción y los 48 compases de la transcripción. El recuadro amarillo sigue el compás activo desde la introducción.

| Negra por minuto | Proporción | Vídeo |
| ---: | ---: | --- |
| 36 | 50 % | [MP4](intermezzo-estudio-36.mp4) |
| 54 | 75 % | [MP4](intermezzo-estudio-54.mp4) |
| 72 | 100 % | [MP4](intermezzo-estudio-72.mp4) |

Los tempos de práctica toman como referencia la negra = 72 de la [partitura de Violín I](../../intermezzo.pdf). Desde la raíz, `python3 render_compas_activo.py intermezzo` regenera los tres vídeos desde la fuente LilyPond. Las variantes imprimen el tempo propio de cada vídeo.
